# Awesome Component Libraries 收录标准

仅用于 `wiki/topics/frontend/awesome-component-libraries.md`，与 [resource-catalogs.md](resource-catalogs.md) 的通用标准一起使用。收录组件库、视觉效果库和 CSS 参考站。

## 按用途核对

- 接入项目的库：框架与版本要求、浏览器支持、依赖；涉及服务端渲染时再看 SSR 与 hydration。
- 交互组件：响应式布局、样式覆盖、键盘操作、焦点与可访问性；动画再看减少动态效果的设置。
- 性能与维护：运行时代价、包体或资源加载是否影响使用；复制源码后是否需要自行跟进修复。
- 样式与设计参考：示例能否说明具体效果、代码与展示是否对应、适合什么布局；纯教程按学习价值评审，不要求安装测试。

例如圆角库要看裁剪对弹出内容和焦点显示的影响，CSS 对照站要看示例的布局条件与浏览器支持。只展示效果、没有交代关键交互的库可以作参考，不据此宣称可直接用于所有项目。

## 分级含义

| 档 | 含义 |
| --- | --- |
| **推荐** | 可直接抄进项目的成品质量高；文档（Props / 交互 / 安装）完整；许可明确可商用；或有范式价值 |
| **可参考** | 有真实可抄价值，但有短板：复刻归属需自查、依赖较重或需实测、文档偏薄 |
| **偏薄** | 只有链接 / 简介级信息，缺少进一步分析或实测；默认不装，只作反例或起点 |

范围较大的 UI 框架不因体积或类别直接排除；先判断是否有本索引需要的具体价值。需要比较多个完整方案时另写 comparison。
