# Lisse：官网与使用限制

## 来源事实

- [官网](https://corne.rs/)将 Lisse 定义为绘制 squircle（平滑圆角）的 JavaScript 库，提供 React、Vue、Svelte 绑定和不依赖框架的 core；支持单独设置四个角、边框和阴影。
- 官网有平滑效果与普通圆角的对照演示，安装入口为 `@lisse/react`、`@lisse/vue`、`@lisse/svelte`、`@lisse/core`。
- [官方文档目录](https://github.com/JaceThings/Lisse/wiki)提供安装、效果配置、SSR、性能与限制说明。
- [Limitations](https://github.com/JaceThings/Lisse/wiki/Limitations)说明：自动读取 CSS 边框和阴影只在挂载时执行一次；React、Vue 组件多包一层 div，可能影响 Flex/Grid 布局；超出裁剪区域的子内容会被切掉。
- [LICENSE](https://github.com/JaceThings/Lisse/blob/main/LICENSE)为 MIT，使用或分发时仍须保留版权与许可声明。

## 收录判断

分级：**可参考**。适合需要 Figma 风格平滑圆角的卡片或按钮；有演示、安装入口和限制文档。本次只阅读文档，未安装或实测，不能据此保证在现有项目里直接替换圆角样式即可。接入时应检查布局、弹出内容和键盘焦点的显示。
