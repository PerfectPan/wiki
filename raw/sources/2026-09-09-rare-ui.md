## 分发与依赖

- 安装：`npx shadcn@latest add swamimalode07/rare-ui/<component>`（任意包管理器）
- 每个组件是单文件、归使用者所有："a single file you own, not a dependency you install"（shadcn registry 分发模式）
- 技术栈：React + TypeScript；组件依赖 `motion`（OTP Input 页标注 Dependencies: motion）；Fluid Orb 为 WebGL 实现
- reduced-motion：Ambient 类组件（如 Fluid Orb）在 `prefers-reduced-motion` 下停在一帧静止画面

## 组件页结构（抽查 fluid-orb / otp-input）

- 页面均含：Interaction Type（交互方式描述）、Props 表、Installation、用法 snippet、Source Code 查看入口、Credits
- 例 OTP Input：`length` / `size` / `value` / `onChange` / `onComplete` / `status(idle|success|error)` / `mask` 等，支持键入跳格、退格回退、方向键、粘贴与短信自动填充；成功逐格描绿环、错误整行红摇
- 例 Fluid Orb：ChatGPT voice mode 风格 WebGL 流体球，Ambient 自驱漂移；props：`color` / `size` / `className`
