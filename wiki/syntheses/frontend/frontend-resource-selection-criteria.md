# 前端组件与样式参考的收录标准

## 要回答的问题

一个组件库、视觉效果库或 CSS 参考站，是否值得加入 [[wiki/topics/frontend/awesome-component-libraries|Awesome Component Libraries]]？本页集中维护该索引的分级标准；这是本 Wiki 的编辑判断，不是来源作者的评级。

## 先核对什么

- **用途**：读者遇到什么问题时会用到它？
- **用法**：它提供可安装的包、可复制的代码，还是用来学习的示例？需要哪些框架或依赖？
- **限制**：文档是否说明浏览器兼容性、布局、服务端渲染或交互方面的注意事项？尚未验证的内容要明说。
- **许可**：安装或复制代码前，能否找到许可和署名要求？只作阅读参考的站点，也不能默认其代码可任意复用。
- **证据**：至少读过具体示例或使用文档，并在原始资料中记录来源、判断理由和未验证项。

## 分级

| 档 | 含义 |
| --- | --- |
| 推荐 | 示例有明确复用价值，使用说明和许可清楚；影响主要用途的限制已核对，或有值得学习的典型做法。 |
| 可参考 | 有具体用途和示例，但接入表现、兼容性或许可等仍有待核对的部分。 |
| 偏薄 | 材料不足以指导使用；仅在能说明具体问题、具有教学价值时作为反例收录，否则留在原始资料中。 |

“推荐”不表示适用于所有项目；“可参考”也不表示质量差。分级反映目前掌握的证据，未经运行验证的内容不能写成实测结果。
