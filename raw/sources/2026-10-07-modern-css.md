# Modern CSS：新旧写法对照站

## 来源事实

- [首页](https://modern-css.com/)按布局、动画、排版等主题展示旧写法和现代替代写法，并提供浏览器兼容性筛选。
- [居中示例](https://modern-css.com/centering-elements-without-the-transform-hack/)把绝对定位加 transform 的居中方法与 Grid 的 `place-items: center` 并排展示。
- 页面把浏览器支持区分为 Widely available、Newly available、Limited；不能把站点标题中的“可立即使用”理解为所有示例都兼容目标浏览器。

## 收录判断

分级：**可参考**。适合写样式时快速查找更简短的 CSS 写法，不需要为站点本身新增主题页。本次抽查首页与居中示例，未逐项验证兼容性；项目采用前仍需核对目标浏览器和布局是否适用。本次未确认全站代码的统一复用许可，不将其标为可任意复制的开源组件库。
