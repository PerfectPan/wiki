# Awesome Agent Skills 收录标准

仅用于 `wiki/topics/ai/awesome-agent-skills.md`，与 [resource-catalogs.md](resource-catalogs.md) 的通用标准一起使用。收录能体现具体工作方法的外部 Agent skill。

## 核对实际工作流程

- 触发条件：description 是否说明什么时候使用，任务范围是否清楚。
- 交付内容：最后生成什么文件、修改什么对象，谁使用结果；不能只有目标口号。
- 具体限制：是否说明常见错误、环境依赖、工具使用范围与必要的权限要求。
- 结果检查：如何知道任务完成、产物可用；失败时如何报告或处理。阅读脚本与示例，区分写在说明里的要求和实际实现。

领域分析与案例见仓库的 `wiki/syntheses/ai/skill-engineering-artifact-protocol.md`；这里只维护收录操作，不复制那篇知识页。

## 分级时的重点

- 推荐：交付内容、执行限制和结果检查清楚，并包含有价值的具体做法，可作为工程范例或采用候选。
- 可参考：有明确用途和实际约束，但交付方式、检查或失败处理仍不完整。
- 偏薄：接近 README 摘要，只在有明确教学价值时作为起点或反例；不默认建议安装。

只提供人格或文风的 prompt 包、没有实际工作方法的命令备忘，以及本仓库自己的工作流不进入这个外部 skill 索引。热度不能代替内容评审。

简短条目直接链接 skill 来源；只有值得单独保存的摘录、代码分析或验证记录才建 raw 文件。原有来源记录仍按其内容价值保留，不为统一格式批量清理。
